## 2. 固定安排进任务清单

- 数据模型给 `activity` 增加 `kind: 'club' | 'other'`。
- 总览和全部任务共用同一份渲染逻辑，在「已完成」之前插入「固定安排」分组。
- 每张卡片显示：类型标签（社团 / 其他）、星期、名称、时间段、地点、下次发生时间；右侧保留删除按钮。
- 「下次」按周计算：今天还没开始就显示今天，已经过了就顺延到下周；单次安排过期显示「已结束」。
- 固定安排不参与任务完成度、优先级和 `.ics` 导出，只作为排程约束和时间提醒。

## 3. 返回键

- 学习计划页左上角有「← 返回」按钮，走内部 `viewStack`，不是浏览器历史，避免把页面退回空白或跳出应用。
- 从总览 → 学习计划 → 返回，回到总览；从全部任务 → 学习计划 → 返回，回到全部任务。
- 栈为空时兜底回总览，并提示「已返回总览」。

## 4. 静室（白噪音 / 纯音乐）

名字取「静室」，入口在总览页「手动添加」后。

- **5 段内置声音**：雨落窗台（雨声 + 低频）、粉噪专注（粉红噪音）、深夜列车（棕噪 + 低音铺底）、清晨咖啡（暖噪 + 和弦）、海浪呼吸（慢 LFO）。
- 全部由浏览器 **Web Audio 实时合成**，不联网、不占安装包、离线可用；这也是一版「零网络请求」原则的延续。
- **在线 CC0 曲库**：播放器里给了 [Open Lo-Fi](https://github.com/btahir/open-lofi) 的链接（CC0 1.0，150+ 首 lo-fi / ambient），学生可自行下载后用「导入本地音乐」播放。
- **导入本地音乐**：`<input type="file" accept="audio/*">`，只在内存里用 `URL.createObjectURL`，不上传；关闭页面后需要重新导入。
- 支持循环、音量、15/30/45/60 分钟定时停止；收起弹层后音乐继续，左下角有迷你播放器可暂停/停止。

> 为什么内置曲目是合成的：原型要能离线双击打开，不能依赖外部 CDN；合成白噪在任何机器上都能立即播放，且没有版权问题。真实曲库通过 CC0 链接 + 本地导入补齐。

## 5. 自习室

- 打开时从 `BG.model.weekPlan(now).days[0]` 里取 **任务块**，**过滤掉活动块**（社团和其他活动），合并同一任务在今天的多个块。
- 每件显示任务名、课程、今天计划份额和预期分钟数；默认全选。
- 学生可以取消勾选（删减任务），也可以直接改每件的预期分钟数；总时长实时重算。
- 本次专注时长默认等于已选任务总时长；如果手动改小，开始前会提示「专注时长不够完成已选任务」。
- 开始后进入倒计时：不可暂停；勾选完成会按「本次分钟数 / 任务预估」折算成任务进度，写回任务清单。
- 时间到自动结算：显示完成 X / Y 件和未完成列表；可「再开一轮」或回总览。
- 提前离开（关闭、Esc、点遮罩）会先弹「专注还没结束」确认，防止误触中断。

## 6. 数据与兼容

```js
activity = { id, title, kind: 'club'|'other', day: 1..7, start, end,
             repeat: 'weekly'|'once', date, place }
```

- 旧数据没有 `kind` 时按 `club` 处理，不需要迁移。
- 静室的曲目、音量、定时只在页面会话里生效，不写 localStorage；导入的音频文件不落盘。
- 自习室会话不持久化；刷新页面会中断，避免「以为还在计时」。

## 8. 已知取舍

- 内置声音是合成氛围声，不是带旋律的完整歌曲；要听真实 lo-fi 曲目请从 Open Lo-Fi 下载后导入。
- 自习室只取「今天计划里的任务块」，不含目标和活动；目标是每天固定时间，不当作一次性的任务结算。
- 自习室不暂停、不后台计时唤醒；页面关闭或刷新即中断。
- 固定安排仍按每周重复建模，单次活动需要手动录成一次性数据（当前界面默认每周）。
