# 不鸽 · Deadline Radar —— 5 分钟演示视频脚本

> 对应赛题要求：MP4，≤ 5 分钟，≤ 100MB，全程录屏 + 解说。
> 本文与项目文档第七章一致，可直接照着录。

## 一、录制前准备

| 项目 | 设置 |
| --- | --- |
| 录屏 | 1920×1080，30fps；Win + G（Xbox Game Bar）或 OBS |
| 浏览器 | Chrome / Edge，缩放 100%，隐藏书签栏，关掉无关标签页 |
| 数据 | 打开 `buge/index.html?state=empty` 清空，再在设置页点「恢复示例数据」 |
| 音频 | 耳机麦克风，先录 5 秒试听；旁白语速约 4 字/秒 |
| 鼠标 | 移动放慢，点击后停 0.5 秒再说话，方便后期对轴 |

## 二、分镜与解说词

### 0:00–0:20　开场（黑底标题页）

**画面**：黑底，白字「三个平台，三个截止时间」。
**解说**：
> 「周三晚上九点，你想起高数作业。打开 MOOC，截止明晚；切到学习通，实验下周三交；再翻班级群，三天前还有一条论文通知。三个平台，三个截止时间——你还记得哪个先交？」

### 0:20–1:00　产品全景（主界面）

**画面**：主界面，鼠标缓慢划过雷达、焦点卡、右栏计划。
**解说**：
> 「不鸽把散落的截止时间收进一张图。左边是来源平台，中间是未来七天雷达、现在最该做的一件事、完整清单；右边是今晚的时间表和提醒。一屏之内，从全局看到今晚。」

### 1:00–2:05　核心闭环：导入与识别

**画面**：点「导入通知」→「填入一段示例通知」→「识别一下」→ 三条结果逐条出现 → 改一个课程名、一个时间 →「导入 3 条」。
**解说**：
> 「核心闭环从这里开始。把平台通知原文粘进来，点识别：它先按空行和编号分条，再逐字段抽出课程、任务、截止时间、平台和成绩占比。右上角四个小圆点，是每个字段的识别把握。识别不准的地方可以直接改——宁可承认不确定，也不替你猜。确认后导入，清单立刻更新。」

### 2:05–2:45　清单与优先级

**画面**：任务清单，指分组、倒计时、优先级分数；打开一条的悬停操作。
**解说**：
> 「清单按已逾期、24 小时内、3 天内、本周、更远分组。每条右侧是倒计时和优先级分数。分数不是拍脑袋：52% 看紧迫度，26% 看成绩权重，22% 看时间够不够——界面上的‘为什么先做它’，就是这三项的翻译。」

### 2:45–3:25　今日作战计划

**画面**：右栏计划，鼠标划过每个时间块；指向底部提示。
**解说**：
> 「更关键的是今晚怎么做。它按每天三小时的预算，把剩余工时切成 45 分钟一块，避开午饭和晚饭；排不下的时候会直接写：今天只排得下 2.5 小时，还有 13.7 小时留给之后几天。不制造‘今晚能做完’的错觉。」

### 3:25–3:55　完成与导出

**画面**：勾掉一项 → 统计与计划变化 → 点右上角下载导出 .ics。
**解说**：
> 「做完一项勾掉，清单、统计和计划同步更新。右上角可以导出日历文件，带两个提醒：提前 6 小时和提前 1 天。导入手机日历后，即使不打开网页也会响。」

### 3:55–4:25　技术可信度

**画面**：设置页，公式区停 2 秒，再滑到解析规则。
**解说**：
> 「整套规则都写在设置页：解析支持哪些写法、优先级怎么算、数据存在哪里。纯前端、零依赖、断网也能跑——现场演示不依赖任何环境。」

### 4:25–5:00　价值与收束

**画面**：回到主界面，定格。
**解说**：
> 「它省下的不是记一条待办的十秒钟，而是反复确认的成本，和临期才发现的代价。现在它还用规则解析，没有平台接口，提醒也依赖页面打开——这些是下一步要补的。不鸽，把通知变成今晚的时间表。」

## 三、后期与交付

- 剪掉加载等待、误点与口误；转场只用硬切，不加花哨特效。
- 字幕可选：把解说词压成一行字幕，字号 ≥ 32px。
- 导出：H.264，1080p，码率 4–6 Mbps；5 分钟约 60–90MB，符合 ≤100MB。
- 文件名：`不鸽-Deadline-Radar-演示视频.mp4`。
