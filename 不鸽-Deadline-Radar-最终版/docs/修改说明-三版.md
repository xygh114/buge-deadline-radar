## 1. 重要性的新结构

紧急度占总优先级 **60% 不变**；重要度占 40%，内部拆成三项：

| 项 | 初始占比 | 任务侧因子 |
| --- | --- | --- |
| 绩点 | 30% | `min(占总评% / 40, 1) × (0.7 + 0.3 × 目标绩点差)` |
| 课程学分 | 30% | `min(课程学分 / 4, 1)` |
| 个人生涯职业规划 | 40% | 任务勾选「与职业规划相关」且职业规划非空 → 1，否则 0 |

```
重要度 = Σ (占比_i × 因子_i) / Σ 参与占比
优先级 = round(100 × (60% × 紧急度 + 40% × 重要度))
```

- **没填职业规划**：职业项不参与，绩点和学分按原比例重分配（默认 50% / 50%）。
- **填了但任务没勾**：职业项仍参与，但该任务职业因子为 0，所以会拉低它的重要度。
- **调整占比**：设置里三根滑杆独立调整；调高 A，另外两项按各自当前值等比让出剩余百分比，合计始终 100%。
  - 例：绩点 30 / 学分 30 / 职业 40，把绩点调到 50，剩余 50 由学分和职业按 30:40 分，变成 50 / 21.4 / 28.6。
- 职业规划是单独一张卡：录入目标 + 调职业占比；任务表单里的「与职业规划相关」是任务侧的开关。

## 2. 固定安排的持续时间

`activity` 新增：

```js
{
  repeat: 'weekly' | 'once',
  weeks: 1..52,          // 每周重复时的持续周数；1 周 = 仅本周
  startWeek: timestamp,  // 从哪一周开始算
  date: 'YYYY-MM-DD'     // 单次日期
}
```

- 设置里「添加固定安排 / 编辑」弹层支持：每周重复、仅本周、单次。
- 每周重复可填持续周数（1–52）；保存时从**本周一**重新起算，改周数立即生效。
- 仅本周 = 每周重复 + 持续 1 周；下周自动不再进入计划。
- 单次 = 指定一个日期，只在那一天出现。
- 到期的安排在任务清单显示「已结束」，计划页不再扣时间；可随时编辑或删除。
- 旧数据没有 `weeks` / `startWeek` 时按「不限周」处理，不做迁移。

## 3. 学校档案导入

设置 →「绩点与学分」→「导入学校文件」，支持：

- `.txt` / `.csv`：`字段=值`、`字段:值` 或 `字段,值`，每行一个字段。
- `.json`：直接给字段对象，或 `{ "settings": { ... } }`。
- 可识别的字段（中英文都行）：
  - `gpaCurrent` / 当前绩点
  - `gpaTarget` / 目标绩点
  - `gpaScale` / 绩点制
  - `creditsEarned` / 已修学分
  - `creditsRequired` / 毕业要求学分
  - `schoolRequirement` / 学校要求（毕业 / 保研 / 奖学金）
  - `careerGoal` / 职业规划
- 只给课程数组（`courses`）时，至少会把学分加总到已修学分。
- 文件只用 `FileReader` 在本机读取，解析后写入设置；不联网、不上传。
- 提供「下载模板」，可先下载 `不鸽-学校档案模板.txt` 再改写。

## 4. 其它变化

- 任务表单去掉旧的「手动重要程度」，改为「与职业规划相关」勾选。
- 任务卡片会给职业规划相关的任务加「职业」小标签。
- 设置页「数据」和「个人生涯职业规划」并排；「绩点与学分」独占一整行，包含绩点、学分、学校要求、导入、两根占比滑杆。
- 二版的固定安排清单、返回键、静室、自习室、学习计划全部保留。

## 6. 取舍

- 职业规划不自动匹配课程，靠任务上的勾选，简单可解释。
- 学校原始成绩单格式差异大，目前只接受模板化的字段；课程数组只加学分，不自动换算 GPA。
- 三项占比按比例联动，不做锁定；如果调到 100/0/0，另外两项就是 0。
- 活动持续周数从保存当周起算，不保留「原起点」的编辑语义。
